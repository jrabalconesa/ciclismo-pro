# Ciclismo PRO

Copia pública de la aplicación Ciclismo PRO. Incluye bicicletas, mantenimiento, AIA, salidas y perfiles locales. Los documentos personales y de biblioteca se conservan en ChatGPT Sites privado. No se incluyen facturas, instrucciones personales, datos guardados de usuarios ni la biblioteca privada.

Publicación estática desde `dist/`.
